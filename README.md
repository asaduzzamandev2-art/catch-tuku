# Tuku Hunt: Loadshed Edition

I want to make a parody game, the game name is catch tuku just like rabbit catching game.



The game map will use Bangladeshi map(whole map) 



The game is to make fun of the current issue regarding electricity. 



Game engine. 

1. Fully bangla

2.  Make the catching really hard and user will be given option to select time to start 30s, 60s, 2 min 

3. Also display funny messages when the user misses the catch but should not impact game play

4. Display final result with 

5. Make sure it represent the electricity 



6. The game should be light themed
